# 10: Settings Page

## What to build

Complete settings page with all sections: Timer, Appearance, Data, and Account (placeholder).

## Acceptance criteria

- [ ] Timer section: start delay, scramble lengths per puzzle, inspection toggle, sound toggle
- [ ] Appearance section: theme toggle (dark/light/sticker) — carries forward existing theme system
- [ ] Data section: export button, import button, clear all sessions (with confirmation)
- [ ] Account section: "Coming soon" placeholder
- [ ] All settings persist via StorageAdapter
- [ ] E2E test: change settings, reload, verify persistence
