# 09: Sound Effects

## What to build

Start and stop beep sounds via Web Audio API, toggleable in settings. No audio files — simple tone generation.

## Acceptance criteria

- [ ] Start beep plays when timer starts
- [ ] Stop beep plays when timer stops
- [ ] Web Audio API tone generation (oscillator-based, no audio files)
- [ ] Settings → Timer: sound toggle (default off)
- [ ] Sound respects the setting (off by default, on when enabled)
- [ ] Unit test: sound plays/stops based on setting
